### 1. The Core Intellectual Property Reference
The baseline algorithm utilizes the Minimum Acceptable Rate (MAR) formula defined under the original YEP framework architecture:
MAR = Cv + (Cf / n)
Where:
- Cv = Variable Cost Per Occupied Room (CPOR baseline housekeeping, utilities, guest consumables)
- Cf = Total Fixed Daily Operating Costs
- n  = Inventory Occupancy Volume
