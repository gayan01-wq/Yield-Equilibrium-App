# Yield-Equilibrium-App

An open-source mathematical framework implementing the **Yield Equilibrium Protocol (YEP)** to protect luxury hospitality asset performance against unaligned pricing algorithms and distribution revenue leakages.

## 📊 Core Architecture
This platform isolates operational revenue management strategies from heavy stochastic modeling. While the application runs core logic processes, macro verification simulations are isolated to prevent memory overhead and maintain platform stability.

## ⚙️ Running the Verification Engine

To locally execute the 10,000-iteration stochastic simulation validating the Yield Equilibrium Protocol, you can run the isolated simulation script:

```bash
python simulation/stochastic_engine.py
